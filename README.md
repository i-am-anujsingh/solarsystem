# 🌌 Solar System Website (Three.js Project)

## 📌 Abstract

This project is an interactive **Solar System visualization website** developed using **HTML, CSS, JavaScript, and Three.js**. The main objective of this project is to create a visually engaging and educational platform that allows users to explore planets in a 3D environment.

The website simulates the solar system with realistic planetary models, animations, and space backgrounds. Each planet has its own dedicated page providing detailed information and interactive visuals. The use of **Three.js (JavaScript 3D library)** enhances the user experience by enabling real-time rendering of 3D objects directly in the browser.

This project helps in understanding both **astronomy concepts** and **modern web development techniques**, especially in 3D graphics and interactive UI design.

---

## 🚀 Features

* 🌍 Interactive 3D Solar System visualization
* 🪐 Individual pages for each planet
* 🌌 Animated star background
* ⚡ Smooth transitions and animations
* 📱 Responsive design (basic)
* 🎮 Real-time rendering using Three.js

---

## 🛠️ Technologies Used

* **HTML (HyperText Markup Language)** – Structure of the website
* **CSS (Cascading Style Sheets)** – Styling and layout
* **JavaScript (JS)** – Logic and interactivity
* **Three.js (3D JavaScript Library)** – Rendering 3D models and animations

---

## 📖 Description of Files

* **index.html** → Main entry page of the website
* **style.css** → Contains all styling and layout design
* **main.js** → Handles core logic and 3D rendering setup
* **starBg.js** → Creates animated star background
* **planets/model.js** → Defines 3D models and configurations for planets
* **planet HTML files** → Individual pages for each planet
